📊 Projeto de Previsão de Score de Crédito com Python
📌 Descrição do Projeto

Este projeto tem como objetivo desenvolver um modelo de Machine Learning capaz de analisar dados de clientes e prever automaticamente seu score de crédito, classificando-os em três categorias:

Ruim

Ok

Bom

A proposta simula um cenário real do setor financeiro, onde instituições precisam avaliar o risco de crédito de clientes para apoiar processos de tomada de decisão.

🎯 Objetivo

Construir um modelo preditivo capaz de:

Analisar informações de clientes

Identificar padrões nos dados

Classificar automaticamente o risco de crédito

🛠 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando:

Python

Pandas

scikit-learn

Algoritmos utilizados:

Random Forest

K-Nearest Neighbors

⚙️ Etapas do Projeto

O projeto segue um fluxo típico de Machine Learning:

1️⃣ Entendimento do problema

Compreensão da necessidade de prever o score de crédito dos clientes.

2️⃣ Importação e exploração da base de dados

Leitura do dataset e análise inicial da estrutura dos dados.

3️⃣ Preparação dos dados

Transformação de variáveis categóricas utilizando Label Encoding.

4️⃣ Separação dos dados

Divisão da base em conjuntos de treino e teste.

5️⃣ Treinamento dos modelos

Treinamento de diferentes algoritmos de classificação.

6️⃣ Avaliação dos modelos

Comparação da precisão utilizando métricas de avaliação.

📈 Resultado

Após a comparação entre os modelos, o algoritmo Random Forest apresentou melhor desempenho na previsão do score de crédito.
